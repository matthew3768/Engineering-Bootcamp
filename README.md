# Software Engineering Bootcamp

Welcome to my software engineering bootcamp.

After graduating with a degree in Software Engineering, I wanted to continue developing my skills before starting a graduate software engineering role.

This repository documents a structured learning journey focused on strengthening the knowledge that employers expect from graduate software engineers.

Each week focuses on a different topic, with daily exercises, mini-projects, reflections, and code reviews.
